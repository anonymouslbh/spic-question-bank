# 国家电投 2025—2027 练习题库与模拟卷

这是一个可直接在浏览器中使用的静态练习题库，包含历年练习题、两套 2027 届模拟卷、题目原图、原始资料以及完整校对记录。

## 使用方法

- 在线使用：[打开国家电投练习题库](https://anonymouslbh.github.io/spic-question-bank/)。
- 本地使用：下载整个仓库后，用 Chrome 或 Edge 打开 `index.html`。
- 模拟考试：从首页进入“模拟考试”，A、B 两套卷各计时 60 分钟，交卷后自动判题。

学习进度、错题、收藏、笔记和模拟考试记录仅保存在使用者自己的浏览器中。仓库本身不包含任何人的答题记录，首次打开时进度为空。

## 内容说明

- 练习题与原图按年份、试卷和专项类型整理。
- 校对记录全部保留，可追溯 OCR 修正、重复题归组、答案核对和图形题复核过程。
- 扫描卷可能存在遮挡、重影、缺页或原题选项矛盾；未能可靠核实的题会明确标注。
- 参考答案来自原卷标注、独立解题或公开资料核验，不作为官方答案保证。

## 主要入口

- `index.html`：练习题库
- `mock.html`：2027 届 A、B 模拟考试
- `mock-review.html`：模拟卷待确认题与校对说明
- `使用说明.txt`：功能和数据说明

本项目仅用于学习交流。
