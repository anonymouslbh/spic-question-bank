# 国家电投 2020—2027 练习题库与模拟卷

这是一个可直接在浏览器中使用的静态练习题库，包含历年练习题、两套 2027 届模拟卷、题目原图、原始资料以及完整校对记录。

## 在线使用

- 练习题库：[打开在线题库](https://anonymouslbh.github.io/spic-question-bank/)
- 模拟考试：进入在线题库后点击“模拟考试”，选择 A 卷或 B 卷。
- 在线版无需安装，电脑和手机浏览器均可打开，建议使用最新版 Chrome 或 Edge。

学习进度、错题、收藏、笔记和模拟考试记录仅保存在使用者自己的浏览器中。仓库本身不包含任何人的答题记录，首次打开时进度为空。

## 下载和本地使用

### 方法一：下载 ZIP（推荐）

1. 打开 [GitHub 仓库主页](https://github.com/anonymouslbh/spic-question-bank)。
2. 点击绿色的 **Code** 按钮，再点击 **Download ZIP**；也可以[直接下载 ZIP](https://github.com/anonymouslbh/spic-question-bank/archive/refs/heads/main.zip)。
3. 下载完成后将压缩包**完整解压**，不要直接在压缩包内运行，也不要只复制 `index.html`。
4. 双击解压目录中的 `启动题库.cmd`。如果系统拦截该文件，也可以用 Chrome 或 Edge 直接打开 `index.html`。
5. 在首页练习，或点击“模拟考试”进入 A、B 两套试卷。

题目图片、模拟卷图片、原始资料和网页文件相互关联，因此需要保留解压后的完整目录结构。

### 方法二：使用 Git 下载

已安装 Git 的同学可以运行：

```bash
git clone https://github.com/anonymouslbh/spic-question-bank.git
```

下载后进入 `spic-question-bank` 文件夹，双击 `启动题库.cmd` 或打开 `index.html`。以后可在该文件夹运行 `git pull` 获取更新。

## 学习记录

- 答题进度、错题、收藏、笔记和模拟考试记录保存在当前浏览器中，不会上传到 GitHub。
- 更换电脑、浏览器或题库目录时，原进度不会自动跟随。需要迁移时，请先在旧题库中导出进度，再在新题库中导入。
- 下载或更新仓库不会带入整理者的答题痕迹。

## 数据和校对说明

- 练习题与原图按年份、试卷和专项类型整理。
- 校对记录全部保留，可追溯 OCR 修正、重复题归组、答案核对和图形题复核过程。
- 扫描卷可能存在遮挡、重影、缺页或原题选项矛盾；未能可靠核实的题会明确标注。
- 参考答案来自原卷标注、独立解题或公开资料核验，不作为官方答案保证。
